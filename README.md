# Wisdom Obinna — Developer Portfolio

A responsive personal portfolio built with semantic HTML, modern CSS and vanilla JavaScript. It presents my development profile, services, selected live projects and contact links.

## Live projects featured

- **GitSeek** — https://gitseek-gitfinder.vercel.app
- **G-store Boutique** — https://gstoreboutique.vercel.app
- **Savour** — https://restsavour.vercel.app

## Tech stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox and responsive media queries)
- Vanilla JavaScript
- Google Fonts (DM Sans and Manrope)

## Run locally

No build tools or package installation are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/wisdomobinna12123-webdev/my-portfolio.git
   ```
2. Open the project folder.
3. Start a local static server, or open `index.html` in your browser.

For VS Code, you can use the Live Server extension.

## Add your profile photo

1. Put your image inside the `assets` folder.
2. Name it exactly `profile.jpg`.
3. Use a portrait image (a square image of 800 × 800 pixels or larger works well).

The page displays a designed initials placeholder automatically if the photo is missing.

## Update project details

The project cards currently link to these live demos:

- GitSeek
- G-store Boutique
- Savour

Update the project descriptions and technology labels in `index.html` when the project scope changes. Use real screenshots and verified repository links when available.

## Customise the design

The primary accent is `#3b2ef8`. Theme tokens are defined at the top of `style.css`:

- `--primary`: primary accent
- `--bg`: page background
- `--surface`: card and panel background
- `--text`: primary text
- `--muted`: secondary text

The theme toggle stores the selected appearance in localStorage.
